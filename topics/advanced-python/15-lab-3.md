## Теоретическая справка

### А. Объектно-ориентированный дизайн

Лабораторная требует **нескольких классов** с явными ролями:

| Класс | Ответственность |
|-------|-----------------|
| `FileRecord` | Данные об одном файле (dataclass или обычный класс) |
| `ScanResult` | Агрегат: список записей, ошибки, статистика |
| `DirectoryScanner` | Обход ФС, создание `FileRecord` |
| `ReportWriter` | Сериализация `ScanResult` в JSON |
| `CatalogApp` / `main` | Сборка зависимостей, CLI, exit codes |

Принципы:

- **Single Responsibility** — сканер не пишет JSON на диск; writer не обходит дерево.
- **Инкапсуляция** — внутренние детали обхода скрыты за методом `scan(root: Path) -> ScanResult`.
- **Композиция предпочтительнее наследования** — `CatalogApp` принимает scanner и writer в `__init__`.

```python
from dataclasses import dataclass
from pathlib import Path


@dataclass(frozen=True)
class FileRecord:
    path: str          # относительный путь от root
    size_bytes: int
    extension: str
```

### Б. Файловая система: os, sys, pathlib

Из [модуля 14](14-filesystem-os-sys.md):

- `sys.argv` / `argparse` — аргументы CLI.
- `os.walk` или `Path.rglob` — обход дерева.
- `os.path.join` / `Path` — переносимые пути.
- `sys.exit(code)` — код для shell.
- `os.environ` — опциональный `CATALOG_SKIP_DIRS` (список через `:`).

**Рекомендация:** внутреннее представление путей — `pathlib.Path`; при необходимости совместимости с `os.walk` конвертируйте через `str(path)`.

### В. Обработка исключений

Сканирование **не должно падать** из-за одного недоступного файла:

```python
try:
    size = path.stat().st_size
except OSError as exc:
    errors.append(ScanError(path=rel, message=str(exc)))
    continue
```

Иерархия:

- **Ожидаемые** — `OSError`, `PermissionError` → записать в `ScanResult.errors`, продолжить.
- **Ошибки ввода** — несуществующий root → сообщение в stderr, `sys.exit(2)`.
- **Программные** — не глотать `KeyboardInterrupt`; не ловить голый `except:`.

Используйте `logging` или stderr для ошибок; успешную сводку — в stdout.

### Г. Опционально: threading или asyncio

Етап сбора метаданных **I/O-bound** (много `stat()` на диске). На больших деревьях можно:

| Подход | Когда |
|--------|-------|
| Последовательный | До ~1000 файлов, простота |
| `ThreadPoolExecutor` | Блокирующий `stat`, legacy-код |
| `asyncio` + `asyncio.to_thread` | Если уже async-стек |

Бонус **не обязателен** для зачёта; базовый уровень — последовательный скан.

### Д. Формат отчёта JSON

```json
{
  "root": "/abs/path/to/data",
  "scanned_at": "2026-07-03T10:00:00Z",
  "platform": "linux",
  "total_files": 42,
  "total_bytes": 1048576,
  "by_extension": {".py": 10, ".md": 5},
  "files": [
    {"path": "src/main.py", "size_bytes": 1200, "extension": ".py"}
  ],
  "errors": [
    {"path": "secret.bin", "message": "[Errno 13] Permission denied"}
  ]
}
```

## Эталонное решение (outline)

> Полный код не прилагается намеренно — вы собираете его по шагам. Ниже — **скелет** эталона для сверки архитектуры.

### models.py

```python
from __future__ import annotations

from dataclasses import dataclass, field
from pathlib import Path


@dataclass(frozen=True)
class FileRecord:
    path: str
    size_bytes: int
    extension: str


@dataclass(frozen=True)
class ScanError:
    path: str
    message: str


@dataclass
class ScanResult:
    root: Path
    records: list[FileRecord] = field(default_factory=list)
    errors: list[ScanError] = field(default_factory=list)

    def summary(self) -> dict:
        by_ext: dict[str, int] = {}
        total_bytes = 0
        for rec in self.records:
            total_bytes += rec.size_bytes
            by_ext[rec.extension] = by_ext.get(rec.extension, 0) + 1
        return {
            "total_files": len(self.records),
            "total_bytes": total_bytes,
            "by_extension": by_ext,
        }
```

### scanner.py (фрагмент)

```python
import os
from pathlib import Path

from .models import FileRecord, ScanError, ScanResult

DEFAULT_SKIP = frozenset({".git", "__pycache__", ".venv", "venv"})


class DirectoryScanner:
    def __init__(self, *, skip_dirs: frozenset[str] | None = None) -> None:
        self._skip = skip_dirs or DEFAULT_SKIP

    def scan(self, root: Path) -> ScanResult:
        root = root.resolve()
        if not root.is_dir():
            raise NotADirectoryError(root)

        result = ScanResult(root=root)
        for dirpath, dirnames, filenames in os.walk(root):
            dirnames[:] = [d for d in dirnames if d not in self._skip]
            for name in filenames:
                full = Path(dirpath) / name
                rel = str(full.relative_to(root))
                try:
                    st = full.stat()
                except OSError as exc:
                    result.errors.append(ScanError(path=rel, message=str(exc)))
                    continue
                ext = full.suffix.lower()
                result.records.append(
                    FileRecord(path=rel, size_bytes=st.st_size, extension=ext)
                )
        result.records.sort(key=lambda r: r.path)
        return result
```

### report.py (фрагмент)

```python
import json
import sys
from datetime import datetime, timezone
from pathlib import Path

from .models import ScanResult


class ReportWriter:
    def write_json(self, result: ScanResult, output: Path) -> None:
        output.parent.mkdir(parents=True, exist_ok=True)
        summary = result.summary()
        payload = {
            "root": str(result.root),
            "scanned_at": datetime.now(timezone.utc).isoformat(),
            "platform": sys.platform,
            "total_files": summary["total_files"],
            "total_bytes": summary["total_bytes"],
            "by_extension": summary["by_extension"],
            "files": [
                {"path": r.path, "size_bytes": r.size_bytes, "extension": r.extension}
                for r in result.records
            ],
            "errors": [{"path": e.path, "message": e.message} for e in result.errors],
        }
        output.write_text(json.dumps(payload, indent=2, ensure_ascii=False), encoding="utf-8")
```

### app.py (фрагмент)

```python
import argparse
import sys
from pathlib import Path

from .report import ReportWriter
from .scanner import DirectoryScanner


def parse_args(argv: list[str] | None = None) -> argparse.Namespace:
    p = argparse.ArgumentParser(prog="file_catalog", description="Каталогизатор файлов")
    p.add_argument("root", type=Path, help="Корневой каталог")
    p.add_argument("-o", "--output", type=Path, default=Path("report.json"))
    p.add_argument("-q", "--quiet", action="store_true")
    p.add_argument("--version", action="version", version="1.0.0")
    return p.parse_args(argv)


class CatalogApp:
    def __init__(self, scanner: DirectoryScanner, writer: ReportWriter) -> None:
        self._scanner = scanner
        self._writer = writer

    def run(self, root: Path, output: Path, *, quiet: bool = False) -> int:
        try:
            result = self._scanner.scan(root)
        except NotADirectoryError as exc:
            print(f"Ошибка: {exc}", file=sys.stderr)
            return 2

        self._writer.write_json(result, output)
        if not quiet:
            s = result.summary()
            print(f"Файлов: {s['total_files']}, байт: {s['total_bytes']}")
            top = sorted(s["by_extension"].items(), key=lambda x: -x[1])[:3]
            print("Топ расширений:", top)
        return 1 if result.errors else 0


def main(argv: list[str] | None = None) -> int:
    args = parse_args(argv)
    app = CatalogApp(DirectoryScanner(), ReportWriter())
    return app.run(args.root, args.output, quiet=args.quiet)
```
